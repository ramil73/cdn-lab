How a visit travels

  1. Visitor asks

    The browser requests this page and is routed to the nearest edge node.

  2. Cache hit

    If the edge already has a copy, it answers immediately. No trip to the origin.

  3. Origin fetch

    If not, the edge asks the origin once, replies, and keeps a copy for the next visitor.
